## What this changes

The library can preview JSON and Markdown collection imports, edit their titles
and folders, retry failed items, sort by title or content recency, and file selected
prompts together. Search identifies and highlights matching passages. Prompt
details expose complete names, and plain templates can be copied from the library.

The editor supports saving pasted prompts without AI, plain-text output and note
imports with editable titles. Responsive panes switch to tabs before overlapping;
Fill and copy opens a focused reuse view. Discarding template edits preserves
retained variable inputs, recovered drafts are explained, and inputs can be cleared
separately. Mobile controls and collapsible advanced settings reduce clutter.

Light, Dark and System choices are available in the sidebar and Settings, and
Guides can be opened from the app. Hosted AI connections use curated model choices
with labels and estimated prices; local/custom providers retain discovery and
manual entry. Anthropic connections can optionally select a workspace.

Evaluation adds Contains, Does not contain and Valid JSON checks, distinguishes
failed and partially failed runs from pending ratings, and gives actionable
connection guidance. Budget errors explain scope and reset time, preserve test
cases and offer an explicit availability recheck.

The complete list is in the [0.6.0 changelog](../../CHANGELOG.md#060---2026-10-17).

## Upgrade and compatibility

- Back up the database and rehearse the upgrade on an isolated backup copy before
  production deployment. Startup migration `028_prompt_content_updated_at` adds
  the content-edit timestamp and backfills it from `updated_at`, falling back to
  `created_at`. Earlier organization-only activity cannot be reconstructed.
- Startup migration `029_user_llm_workspace` adds nullable `llm_workspace_id`.
  Existing connections retain their settings. Multi-workspace Anthropic keys can
  configure the optional workspace ID in Settings; the shared AI transport sends
  it only to Anthropic's endpoint.
- Prompt responses and exports add `content_updated_at`. Favoriting and filing no
  longer change content recency. AI capability responses add caller budget status;
  budget errors retain `detail` and add recovery metadata. See the
  [API documentation](../api.md).
- Saving an OpenAI, Anthropic or Gemini connection requires a model from the
  curated catalogue; unlisted choices return HTTP 422. Existing older connections
  remain readable, testable and runnable until changed. Updating one requires a
  current model choice; omit `api_key` to retain the saved credential. Operator
  defaults remain unaffected. Prices are estimates, not billing guarantees.
- Collection import creates prompt copies; a full data archive is a separate
  export format. Review the import preview before saving copies.
- Replace both application images together when published. For upgrades from
  before 0.5.0, also follow [Upgrading to 0.5.0](../deployment.md#upgrading-to-050).
- Rollback across schema changes requires a verified pre-upgrade backup and the
  matching prior application images; do not assume downgrading images reverses
  migrations. Keep the current signing and encryption configuration available.
