# 0.16.1 release record

Published on 2026-11-03 (Europe/Berlin):
[GitHub release](https://github.com/chrysogonus/prompt-maker-studio/releases/tag/v0.16.1).
Tag `v0.16.1` points to `352760ce41e9bd11c50af29ec249dddccd4da7c5`.
[Release PR #99](https://github.com/chrysogonus/prompt-maker-studio/pull/99) was merged into
`main` with a merge commit; the tagged commit has the same tree as `dev` at `c6517a8`. The MCP `list_prompt_versions` tool description
now explains its dates: a version is stored when the next edit replaces it, so its `created_at`
is that replacement time, and its content was written when the previous version was replaced
(version 1: the prompt's `created_at`). Assistants could not tell this before. All six version
declarations report `0.16.1`. Production was deployed on 2026-11-03, and `server.json`
0.16.1 was published to the MCP Registry at 00:23 UTC, where it is active and latest.

## Changes and upgrade

The [changelog](../../CHANGELOG.md) lists every change.

**API:** no REST route, request or response schema changes. The MCP tool list changes only in the
`list_prompt_versions` description; tool names, arguments, results, titles and annotations are
unchanged. Clients that cache tool metadata see the new description after refreshing their tool
catalogue. See [MCP endpoint](../mcp.md).

**Database:** no migrations.

**Configuration:** no new settings, and no Compose or `Caddyfile` changes. Upgrade by deploying
the matching backend and frontend images; image publication does not deploy the app.

**Dependencies:** no changes.
