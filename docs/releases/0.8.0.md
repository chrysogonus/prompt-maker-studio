## Changes and upgrade

The [changelog](../../CHANGELOG.md) lists every change. In short:

- **Bringing prompts in.** Add existing prompts is the single entry point for pasted
  text, several files, a folder (such as an Obsidian vault) or dropped files and
  folders. Notion's Markdown & CSV `.zip` export and database `.csv` files import as
  downloaded; the zip is read in the browser with `DecompressionStream`, without a new
  dependency. Notes lose front matter, Notion properties, callouts and trailing tags
  unless the original is kept; placeholders can become inputs with their wording as
  the hint; titles already in the library are skipped unless a copy is requested.
- **Library.** Several prompts can be deleted together with one Undo, search matches
  every word in any order, and the empty library leads with Add existing prompts.
- **Editor and preview.** Saved prompts with variables open ready to fill, sections
  have Insert input, single-section prompts copy as plain text, and controls meet
  3:1 border contrast in both themes.
- **AI features.** Actions say whether they use the user's own provider or the
  server's shared connection. Make reusable with AI keeps inputs empty and leaves
  out notes meant for the prompt's owner. Refine offers Improve without questions.
- **ChatGPT.** Settings has a ChatGPT section with the connector address, the steps
  to connect, and the connected apps with Disconnect.

API additions, all backward compatible:

- `GET /api/auth/me/connected-apps` lists the caller's live OAuth/MCP clients;
  `DELETE /api/auth/me/connected-apps/{client_id}` disconnects one by revoking its
  grant, codes and refresh tokens. See [API reference](../api.md).
- `GET /api/prompts/config` adds `uses_server_default`.
- `POST /api/prompts/refine/draft` accepts a request without `qa_pairs`.

No database migrations, dependency changes, environment variables, Compose or Caddy
changes, or MCP tool schema changes. Upgrade by deploying the matching backend and
frontend images; image publication does not deploy the app.
