# 0.4.0 release record

Not yet published. This record is completed once tag `v0.4.0` is pushed and its
images are on GHCR.

## What this changes

`/` is now a server-rendered landing page for signed-out visitors, so search
engines see what the product does instead of a loading spinner. Signed-in visitors
go straight to `/library`. `robots.txt`, `sitemap.xml`, the canonical link and
social previews are built from `FRONTEND_URL` on each request. The frontend image
now ships `public/`, which fixes the 404s for the PWA icons. `server.json`
describes the hosted MCP endpoint for the official MCP Registry.

Type of change: Feature · Bug fix · Docs.
Related work: [PR #50](https://github.com/chrysogonus/prompt-maker-studio/pull/50).

## Upgrade and compatibility

- No database migrations.
- **Update `docker-compose.yml` on the server, not only `IMAGE_TAG`.** The
  frontend service now receives `FRONTEND_URL`; with the old Compose file it falls
  back to `http://localhost:3000`, and robots.txt, the sitemap and canonical links
  would point there. Check that `.env` sets `FRONTEND_URL` to the public origin.
- `/` no longer redirects everyone to the library: visitors without a session
  cookie see the landing page. Bookmarks to `/` still reach the library once
  signed in.
- Installed PWAs now start at `/library`.

## Checks

- PR #50: all CI quality gates passed, including browser end-to-end tests and the
  Docker build validation.
- The production frontend image was built locally and served `/landing/editor.png`,
  `/landing/library.png`, `/icon-512.png` and `/apple-touch-icon-180.png` (200).
