# 0.12.0 release record

Published on 2026-10-28 (Europe/Berlin):
[GitHub release](https://github.com/chrysogonus/prompt-maker-studio/releases/tag/v0.12.0).
Tag `v0.12.0` points to `1d78e1040bb0124ba80ab646b08b16ceffacb05c`.
[Release PR #82](https://github.com/chrysogonus/prompt-maker-studio/pull/82) merged `dev`
into `main`, preserving ancestry. The tagged merge has the same tree as `413e8d5`. The
release collects the fixes from the 2026-10-27 SEO audit of the public site: structured
data, server-rendered legal links, tighter search titles, faster landing images, an About
page, a ChatGPT and Claude connection guide, `llms.txt`, and fuller gallery pages and
guides. All six version declarations report `0.12.0`. Production deployment and MCP
Registry publication were not performed.

## Changes and upgrade

The [changelog](../../CHANGELOG.md) lists every change. In short:

- **Structured data.** The home page, guides, tools, gallery templates and the three
  indexes describe themselves as JSON-LD, credited to the open-source project rather
  than the operator (see the decision log). Guides show an updated date, which also
  feeds `sitemap.xml`.
- **Legal pages.** Footer links to the operator's Impressum, privacy policy and terms
  are in the server-rendered HTML, the pages have their own description and canonical
  link, the sitemap lists the ones a deployment provides, and `/privacy` and `/imprint`
  redirect to them.
- **Search titles and links.** Gallery template titles stay under 60 characters, long
  descriptions are shortened, tool titles start with "Free", and every gallery template
  is linked from its category neighbours.
- **Landing images.** Screenshots load as responsive WebP and `/landing/*` is cached for
  a day; pages keep `Cache-Control: no-store` (see the decision log).
- **New public pages.** `/about`, a guide to using the library in ChatGPT and Claude that
  shows the deployment's own MCP address, a "What is a prompt library?" guide, and
  `/llms.txt`.
- **Fuller content.** Gallery templates show their prompt filled in with the example
  inputs and what a good result looks like; the coding-agent guide includes all six
  coding templates; the variables guide compares placeholder syntax across tools, with
  sources.

API changes: none. The backend is unchanged apart from its version.

**Database:** no migrations.

**Configuration:** no new or changed settings, and no Compose, Caddy or MCP tool
changes. Operators who mount legal pages should give each file a single `<h1>`; see
[Legal Pages](../deployment.md#legal-pages-impressum-privacy-policy). The frontend no
longer sends `X-Powered-By`. Upgrade by deploying the matching backend and frontend
images; image publication does not deploy the app.

**Dependencies:** no changes. The new WebP screenshots were generated once, offline, and
are committed under `frontend/public/landing/`.
