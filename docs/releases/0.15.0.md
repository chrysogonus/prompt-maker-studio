# 0.15.0 release record

Published on 2026-11-02 (Europe/Berlin):
[GitHub release](https://github.com/chrysogonus/prompt-maker-studio/releases/tag/v0.15.0).
Tag `v0.15.0` points to `ece3045824a0180ea40ac5dcf5494c438752807a`.
[Release PR #90](https://github.com/chrysogonus/prompt-maker-studio/pull/90) was squash-merged
into `main`, so `main` does not carry `dev`'s individual commits; the tagged commit has the same
tree as `dev` at `f10e3a0`, and `814b526` merged `main` back into `dev` without changing any
file. The release fixes the findings of the 2026-10-31 UX test: a reworked saved-prompt header (one Edit | Fill and copy switch, Refine and
Evaluate as buttons, a More menu), one vocabulary for variables, values and placeholders, and
accessibility, library, evaluation, editor, sign-in and public-page fixes. It also raises the
reverse proxy's write timeout so long evaluation runs are not cut off. All six version
declarations report `0.15.0`. Production deployment and MCP Registry publication were not
performed at publication time.

## Changes and upgrade

The [changelog](../../CHANGELOG.md) lists every change. The new header layout is recorded in the
[decision log](../../product/DECISIONS.md); the deferred follow-ups are in the
[backlog](../../product/BACKLOG.md).

**API:** no route, request or response schema changes. `POST /api/prompts/{id}/duplicate` names
the copy "Name (copy)", then "Name (copy 2)", instead of "Name Duplicate". See
[API reference](../api.md).

**Database:** no migrations.

**Configuration:** the `Caddyfile` write timeout is `15m` (was `30s`), so HTTP/1.1 and HTTP/2
clients receive evaluation runs that take longer than 30 seconds. Production has run with this
value and `LLM_TIMEOUT_SECONDS=180` since 2026-10-30. Caddy mounts the `Caddyfile` as a single
read-only file, so a changed file needs a restart of the Caddy container, not only
`caddy reload`. No new settings, and no Compose or MCP tool changes. Upgrade by deploying the
matching backend and frontend images; image publication does not deploy the app.

**Dependencies:** no changes.
