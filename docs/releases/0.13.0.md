## Changes and upgrade

The [changelog](../../CHANGELOG.md) lists every change. In short:

- **One project entity.** The `Organization` in every page's structured data has a stable
  `@id`, the logo, the repository as `sameAs` and its maintainer; tool pages name it as
  publisher too. It stays the open-source project, never the operator (see the decision log).
- **About page.** `/about` says who builds the project, where to report problems and read
  release notes, and how the app handles prompts and optional AI connections. It now follows
  the visitor's system theme like the other public pages.
- **Search titles and targets.** Titles stay within 60 characters, `/privacy` and `/imprint`
  redirect permanently (308), and the home page's search title leads with the template
  editor, leaving "prompt library" to the gallery and the new guide.
- **Sitemap dates.** Each free tool and gallery template has its own last-modified date, kept
  with its content; pages without a reliable date stay undated.
- **Content.** Research and everyday templates show a written example of a good result,
  every template has at least two tips, the coding guide has a Copy button per template, and
  the coding, image and research guides link the provider guidance they draw on.
- **Token counter.** It says how current its prices are.
- **Documentation.** README, `docs/`, product records, the contributing guide and agent
  instructions were checked against the code and updated.

API changes, all backward compatible:

- `GET /api/public/model-prices` adds `prices_as_of`, the ISO date each price was fetched
  from the live index or last checked for the built-in list (`null` when unpriced).

See [API reference](../api.md).

**Database:** no migrations.

**Configuration:** no new or changed settings, and no Caddy or MCP tool changes; Compose
changed only in a comment, and `.env.example` only in its `FRONTEND_URL` description.
Upgrade by deploying the matching backend and frontend images; image publication does not
deploy the app.

**Dependencies:** no changes.
