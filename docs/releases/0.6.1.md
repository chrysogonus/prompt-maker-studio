# 0.6.1 release candidate

Prepared on 2026-10-17 (Europe/Berlin). Not tagged, published or deployed.
The latest published release remains 0.6.0. Backend package/API, frontend
package/lock metadata and `server.json` report the candidate version `0.6.1`.

## Changes and compatibility

- All five MCP tools explicitly declare `readOnlyHint`, `destructiveHint` and
  `openWorldHint`.
- `update_prompt` advertises `destructiveHint: true` because it replaces current
  prompt content. Version history and optimistic concurrency remain unchanged.
- `save_prompt` remains an additive, non-destructive write; retrieval tools remain
  read-only. All tools remain confined to the authenticated user's library.
- No database migrations, dependency changes or tool input/output schema changes.
  ChatGPT may request confirmation for updates based on the corrected annotation.
- Deploy the published application images before refreshing the ChatGPT tool
  catalogue or scanning tools in the submission portal. Release publication alone
  does not update the live MCP endpoint.

The separately managed legal documents are not bundled in this release. Their
deployment is independent of the application images.

## Validation

- Before release preparation, `make lint-backend` passed and `make test` passed
  all 968 backend tests. The updated MCP metadata regression check covers all
  five tools; it reproduced the missing annotation before the fix.
- On 2026-10-17 (Europe/Berlin), `COMPOSE_DISABLE_ENV_FILE=1 make ci-local`
  passed on the candidate (exit 0), without loading the operator's root `.env`:
  - 968 backend tests passed with 97.07% coverage, above the 90% gate.
  - 367 frontend tests across 37 files passed with coverage thresholds met.
  - All 65 Playwright browser tests passed against an isolated Compose stack.
  - Secret scans, dependency lock checks, lint/types, backend security, production
    frontend dependency security, production builds, Compose, monitoring,
    backup/restore ownership, Docker-context exclusions, image build/smoke checks
    and third-party notices passed.
  - Neither application image has fixable HIGH/CRITICAL vulnerability findings.
- The informational full frontend audit reports five high-severity findings in
  the development-only `braces`/ESLint chain also documented for 0.6.0. The
  production dependency audit reports zero vulnerabilities.
- All six version declarations read `0.6.1`. These notes were updated after CI
  to record its results; application code and version metadata were not changed
  after verification. Final whitespace and release-document link checks passed.

Local CI does not run GitHub CodeQL, publish artifacts, test a live AI provider
or deploy to production. No production deployment or migration rehearsal is
claimed here.
