## What this changes

Dark mode gets quieter, near-neutral surfaces with clearer steps between them,
and plum is kept for navigation, selected states and the preview. Both themes
now share one layout, so switching theme never moves content or changes what
fits. A saved theme applies before the first paint on every page.

The editor puts Evaluate, Paste a prompt and History for saved prompts in a
Tools menu, and Try once moves into a collapsible Test with AI panel. The
sidebar links to the source code, and the landing page shows a worked example
of a template being filled in.

Fixes from the 2026-10-15 UI and UX review:

- The library grid kept two columns in windows too narrow for them, which cut
  off card actions. It now keeps one column until two whole cards fit.
- The library, folder and Starter templates menus announced menu semantics
  without menu keyboard behavior. They are now plain lists of buttons, and
  Escape closes them and returns focus to the button that opened them.
- Closing a dialog lost keyboard focus when a field inside it took focus on
  opening. Dialogs now return focus to their opener; Paste a prompt opened from
  a link falls back to its button.
- Settings now calls the feature Paste a prompt, matching the editor.

Type of change: Feature · Bug fix · Accessibility.
The complete list is in the [changelog](../../CHANGELOG.md).
