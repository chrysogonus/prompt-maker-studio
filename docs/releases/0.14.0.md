# 0.14.0 release record

Published on 2026-10-29 (Europe/Berlin):
[GitHub release](https://github.com/chrysogonus/prompt-maker-studio/releases/tag/v0.14.0).
Tag `v0.14.0` points to `bf56cd03169a638fcda3ae3b450a653910941d24`.
[Release PR #86](https://github.com/chrysogonus/prompt-maker-studio/pull/86) was squash-merged
into `main`, so `main` does not carry `dev`'s individual commits; the tagged commit has the same
tree as `dev` at `551b1ea`. The release collects the open Dependabot updates for the backend,
the frontend and CI, and adds [How it works](../how-it-works.md), a plain-language, visual
overview of the project. It has no feature, API or data changes. All six version declarations
report `0.14.0`. Production deployment and MCP Registry publication were not performed at
publication time.

## Changes and upgrade

The [changelog](../../CHANGELOG.md) lists every change.

No API changes. See [API reference](../api.md).

**Database:** no migrations.

**Configuration:** no new or changed settings, and no Compose, Caddy or MCP tool changes.
Upgrade by deploying the matching backend and frontend images; image publication does not
deploy the app.

**Dependencies:**

- Backend runtime: `fastapi` 0.156.8 (from 0.146.0), and `httpx2` and `httpcore2` 2.16.0
  (from 2.14.0). None of these is a security fix.
- Frontend runtime: `next` and `@next/env` 16.4.2 (from 16.4.1) and `lucide-react` 1.61.0
  (from 1.57.0). The [third-party notices](../../THIRD_PARTY_NOTICES.md) list the new
  versions.
- Development only: `@axe-core/playwright` 4.14.0, `eslint-config-next` 16.4.2, and
  `@typescript-eslint/eslint-plugin` and `@typescript-eslint/parser` 8.72.0. The lockfile now
  holds a single `typescript-eslint` 8.72.0, because `eslint-config-next` still resolved 8.71.2
  and ESLint rejects two copies of the plugin.
- CI: `actions/checkout` 7.0.1, `actions/upload-artifact` 7.0.2, `actions/setup-node` 7.1.0,
  `codecov/codecov-action` 7.1.1, `docker/setup-buildx-action` 4.4.1,
  `docker/build-push-action` 7.4.0, `docker/login-action` 4.6.0, `docker/metadata-action`
  6.2.0 and `github/codeql-action` 4.39.0, all pinned by commit SHA. The registry login,
  metadata and build-push steps run only in the tag pipeline; this release's tag run was their
  first use, and it published both images.
- Not taken: the frontend major upgrades (TypeScript 7, ESLint 10, vitest 5, jsdom 30) remain a
  separate task, and the frontend image stays on Node 22 LTS rather than Node 25.

## Validation

On 2026-10-29 (Europe/Berlin), `COMPOSE_DISABLE_ENV_FILE=1 make ci-local` passed on
the candidate (exit 0), without loading the operator's root `.env`:

- 1,065 backend tests passed with 97.16% coverage, above the 90% gate.
- 652 frontend tests across 51 files passed with coverage thresholds met.
- All 95 browser tests passed against an isolated Compose stack.
- Secret scans, dependency locks, lint/types, backend and production frontend
  security checks (including `pip-audit`), production builds, monitoring, Docker smoke
  tests and third-party notices passed.
- Neither application image has fixable HIGH/CRITICAL vulnerability findings.

Each update passed the full GitHub pipeline on its pull request (#76, #77, #79) before it
merged into `dev`. Local CI does not run GitHub CodeQL, publish images or deploy the
application.

No application changes followed the recorded local run; `f94735c` added only the validation
notes. GitHub first refused to merge #86 because `dev` and `main` had two merge bases (the
Dependabot branches were cut from `main` but merged into `dev`), so `551b1ea` merged `main`
into `dev` without changing any file. The
[#86 pipeline](https://github.com/chrysogonus/prompt-maker-studio/pull/86/checks),
[`main` pipeline](https://github.com/chrysogonus/prompt-maker-studio/actions/runs/40876140527)
and [tag pipeline](https://github.com/chrysogonus/prompt-maker-studio/actions/runs/40877247182)
passed all quality gates, including CodeQL. Both publish jobs promoted the scanned image
indexes to release tags.

Registry verification confirmed that `0.14.0`, `0.14` and `sha-bf56cd0` resolve to the
matching digest for each image. OCI labels identify version `0.14.0` and the tagged
revision. Both indexes retain provenance and SPDX SBOMs.

The maintainer merged the release PR with the established administrator merge exception after
all quality checks passed. No protection settings were changed and no quality check was
bypassed. When this record was written on 2026-10-29, no Dependabot alerts were open.
