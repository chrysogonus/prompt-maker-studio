## Changes and upgrade

The [changelog](../../CHANGELOG.md) lists every change. In short:

- **Evaluation you can trust a little more.** AI-reviewed results can be rated with
  your own stars, kept beside the AI score, and Run history says how often the AI
  review agreed with you.
- **Runs know what they tested.** Each new run stores the exact template text it
  compiled. Run history labels runs by version or "Unsaved draft", and asks for a
  rerun only when the current text was not tested.
- **Refinement from evidence.** On a saved prompt, Refine can use up to five chosen
  results from the latest evaluation, and Check against test cases compares the draft
  with the current prompt on the user's cases before anything is applied.
- **Known-good versions.** One version per prompt can be marked known good. History
  shows each version's newest test result; library cards show "Tested · N/100" or
  "Tests out of date" for evaluated prompts.
- **Claude.** Claude can connect to the existing MCP server as a custom connector, so
  the AI work runs on the user's own Claude plan. Signing in to the app with a Claude
  subscription is not offered: Anthropic's terms do not allow it. Settings has a
  ChatGPT and Claude section.
- **Import.** Re-importing a changed note can update its prompt as a new version;
  previews take up to 1,000 prompts with per-item selection; over-long titles and
  sections are flagged instead of skipped; Notion and Obsidian parsing fixes.

API changes, all backward compatible:

- `POST /api/prompts/{id}/eval/runs` accepts an optional body `{"fields": [...]}` to
  evaluate unsaved sections. Run responses add `tested_version`, `matches_current` and
  `tested_prompt`; results add `human_score`.
- `POST /api/prompts/{id}/eval/runs/{run_id}/results/{result_id}/rate` also rates a
  scored AI-review result, recording `human_score` without changing scores.
- `POST /api/prompts/refine/draft` accepts optional `evidence` (`prompt_id`, `run_id`,
  1–5 `result_ids`); the server loads and trims the results.
- `PATCH /api/prompts/{id}` accepts `known_good_version` (0 clears). Prompt responses
  and the data export add `known_good_version`; `GET /api/prompts/saved` adds
  `eval_status` and `eval_score`.
- MCP tool results for prompts include the new optional prompt fields; tool names and
  inputs are unchanged. Refresh a client's tool catalogue if it caches schemas.

See [API reference](../api.md).

**Database:** forward-only migrations run at startup and only add nullable columns:
`030_eval_human_score`, `031_eval_tested_prompt` and `032_prompt_known_good_version`.
Existing runs are not backfilled; they keep their recorded version number. Back up the
database before upgrading, as [deployment](../deployment.md) describes.

**Configuration:** `OAUTH_REDIRECT_HOSTS` now defaults to `chatgpt.com,claude.ai` in
the backend, Compose and `.env.example`. A deployment whose `.env` sets it explicitly
must add `claude.ai` there for Claude to connect. The only dependency change is
`certifi` 2026.10.19 for
[GHSA-6q48-6c7w-9gw2](https://github.com/advisories/GHSA-6q48-6c7w-9gw2), published after
the candidate was first prepared and caught by the release PR's `pip-audit`. No Caddy
or MCP tool-name changes. Upgrade by deploying the matching backend and frontend images; image
publication does not deploy the app.

## Validation

On 2026-10-20 (Europe/Berlin), `COMPOSE_DISABLE_ENV_FILE=1 make ci-local` passed on
the candidate (exit 0), without loading the operator's root `.env`:

- 1,008 backend tests passed with 97.17% coverage, above the 90% gate.
- 459 frontend tests across 39 files passed with coverage thresholds met.
- All 68 browser tests passed against an isolated Compose stack.
- Secret scans, dependency locks, lint/types, backend and production frontend
  security checks, production builds, monitoring, Docker smoke tests and
  third-party notices passed.
- Neither application image has fixable HIGH/CRITICAL vulnerability findings.

Lint reports one warning in unchanged `src/app/error.tsx`. Every merged change also
passed `make ci-local` before it reached `dev`.

The rebuilt local stack applied migrations 030–032 cleanly to an existing database.
AI features were tested with mocked providers; refinement and evaluation against a
live model and the Claude connector against a live Claude account have not been
exercised. Local CI does not run GitHub CodeQL, publish images or deploy the
application.
