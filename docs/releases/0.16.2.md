# 0.16.2 release candidate

Prepared on 2026-11-03 (Europe/Berlin) on `dev`. The MCP tool titles are now also sent as
`annotations.title`. 0.16.0 added them as each tool's top-level `title` (MCP spec), but Claude's
connector directory reads the title only from the annotations, so its submission form flagged all
five tools as untitled. All six version declarations report `0.16.2`. The tag, image publication,
production deployment and MCP Registry publication have not happened yet.

## Changes and upgrade

The [changelog](../../CHANGELOG.md) lists every change.

**API:** no REST route, request or response schema changes. In the MCP tool list, each tool's
`annotations` gains a `title` equal to its top-level `title`. Tool names, arguments, results,
descriptions and the other annotations are unchanged. Clients that cache tool metadata see the
change after refreshing their tool catalogue. See [MCP endpoint](../mcp.md).

**Database:** no migrations.

**Configuration:** no new settings, and no Compose or `Caddyfile` changes. Upgrade by deploying
the matching backend and frontend images; image publication does not deploy the app.

**Dependencies:** no changes.

## Validation

On 2026-11-03 (Europe/Berlin), `COMPOSE_DISABLE_ENV_FILE=1 make ci-local` passed on
the candidate (exit 0), without loading the operator's root `.env`:

- 1,068 backend tests passed with 97.16% coverage, above the 90% gate.
- 657 frontend tests across 51 files passed with coverage thresholds met.
- All 95 browser tests passed against an isolated Compose stack, including the accessibility
  audit in dark and light theme.
- Secret scans, dependency locks, lint/types, backend and production frontend
  security checks (including `pip-audit`), production builds, monitoring, Docker smoke
  tests and third-party notices passed. The production `npm audit` found no vulnerabilities;
  the moderate findings are in development-only ESLint dependencies.
- Neither application image has fixable HIGH/CRITICAL vulnerability findings.

Local CI does not run GitHub CodeQL, publish images or deploy the application.
