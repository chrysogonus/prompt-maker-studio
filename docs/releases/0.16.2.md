# 0.16.2 release record

Published on 2026-11-03 (Europe/Berlin):
[GitHub release](https://github.com/chrysogonus/prompt-maker-studio/releases/tag/v0.16.2).
Tag `v0.16.2` points to `3372c833c6b791d0b18490f67b74b5f6fbf1a2cf`.
[Release PR #101](https://github.com/chrysogonus/prompt-maker-studio/pull/101) was merged into
`main` with a merge commit after all quality gates passed; the tagged commit has the same tree as
`dev` at `07fa5d8`. The MCP tool titles are now also sent as
`annotations.title`. 0.16.0 added them as each tool's top-level `title` (MCP spec), but Claude's
connector directory reads the title only from the annotations, so its submission form flagged all
five tools as untitled. All six version declarations report `0.16.2`. Production was deployed on
2026-11-03, and `server.json` 0.16.2 was published to the MCP Registry at 10:27 UTC, where it is
active and latest.

## Changes and upgrade

The [changelog](../../CHANGELOG.md) lists every change.

**API:** no REST route, request or response schema changes. In the MCP tool list, each tool's
`annotations` gains a `title` equal to its top-level `title`. Tool names, arguments, results,
descriptions and the other annotations are unchanged. Clients that cache tool metadata see the
change after refreshing their tool catalogue. See [MCP endpoint](../mcp.md).

**Database:** no migrations.

**Configuration:** no new settings, and no Compose or `Caddyfile` changes. Upgrade by deploying
the matching backend and frontend images; image publication does not deploy the app.

**Dependencies:** no changes.
