# 0.16.0 release record

Published on 2026-11-02 (Europe/Berlin):
[GitHub release](https://github.com/chrysogonus/prompt-maker-studio/releases/tag/v0.16.0).
Tag `v0.16.0` points to `ba50a20e460b47d6b2863dc4c0f60ed946d13879`.
[Release PR #95](https://github.com/chrysogonus/prompt-maker-studio/pull/95) was merged into
`main` with a merge commit, so `dev`'s history is preserved and `dev` at `fcd2246` is a parent of
the tagged commit, with the same tree. Before the merge, the `main` ruleset was changed at the
maintainer's request: it now allows merge commits and no longer requires a linear history. The
release gives the five MCP tools display titles, which Claude's connector directory requires
before a server can be listed, and updates three GitHub Actions used by CI. All six version
declarations report `0.16.0`. Production deployment and MCP Registry publication had not been
done at publication time.

## Changes and upgrade

The [changelog](../../CHANGELOG.md) lists every change.

**API:** no REST route, request or response schema changes. The MCP `tools/list` response now
includes a `title` for each tool (List saved prompts, Get prompt, Save prompt, Update prompt,
List prompt versions). Tool names, arguments, results and annotations are unchanged. Clients
that cache tool metadata show the titles after refreshing their tool catalogue. See
[MCP endpoint](../mcp.md).

**Database:** no migrations.

**Configuration:** no new settings, and no Compose or `Caddyfile` changes. Upgrade by deploying
the matching backend and frontend images; image publication does not deploy the app.

**Dependencies:** CI only: `actions/setup-python` moves to a new pinned commit of v7,
`github/codeql-action` goes from 4.39.0 to 4.39.1 and `docker/login-action` from 4.6.0 to
4.7.0. No application dependency changes.
