# 0.16.0 release candidate

Prepared on 2026-11-02 (Europe/Berlin) on `dev`. The candidate gives the five MCP tools display
titles, which Claude's connector directory requires before a server can be listed, and updates
three GitHub Actions used by CI. All six version declarations report `0.16.0`. The tag, image
publication, production deployment and MCP Registry publication have not happened yet.

## Changes and upgrade

The [changelog](../../CHANGELOG.md) lists every change.

**API:** no REST route, request or response schema changes. The MCP `tools/list` response now
includes a `title` for each tool (List saved prompts, Get prompt, Save prompt, Update prompt,
List prompt versions). Tool names, arguments, results and annotations are unchanged. Clients
that cache tool metadata show the titles after refreshing their tool catalogue. See
[MCP endpoint](../mcp.md).

**Database:** no migrations.

**Configuration:** no new settings, and no Compose or `Caddyfile` changes. Upgrade by deploying
the matching backend and frontend images; image publication does not deploy the app.

**Dependencies:** CI only: `actions/setup-python` moves to a new pinned commit of v7,
`github/codeql-action` goes from 4.39.0 to 4.39.1 and `docker/login-action` from 4.6.0 to
4.7.0. No application dependency changes.

## Validation

the candidate (exit 0), without loading the operator's root `.env`:

- 1,066 backend tests passed with 97.16% coverage, above the 90% gate.
- 657 frontend tests across 51 files passed with coverage thresholds met.
- All 95 browser tests passed against an isolated Compose stack, including the accessibility
  audit in dark and light theme.
- Secret scans, dependency locks, lint/types, backend and production frontend
  security checks (including `pip-audit`), production builds, monitoring, Docker smoke
  tests and third-party notices passed. The production `npm audit` found no vulnerabilities;

Local CI does not run GitHub CodeQL, publish images or deploy the application.
